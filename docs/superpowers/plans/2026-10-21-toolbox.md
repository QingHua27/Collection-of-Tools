# Six Tool C++ Toolbox Implementation Plan

**Goal:** 将五个原工具与新写的原生 ACE 优化模块合并到同一进程，交付单文件工具箱。

**Architecture:** Win32 主窗口管理六页面与唯一托盘；模块使用独立消息线程。录屏、倒计时嵌入页面。ACE 监测已安装组件，以可恢复的 CPU/I/O/内存页优先级调整减少争用。使用新图标，关闭行为默认托盘且可保存为直接退出。

**Tech Stack:** C++20、MSVC 静态运行库、Win32/GDI+/Media Foundation/WGC/WinHTTP、CMake。

## Global Constraints

- 不删除原始工具，不自动运行 ACE，不改变用户现有独立程序开机启动项。
- 模块资源 ID 隔离；所有配置位于 LOCALAPPDATA/CppToolbox，保留原始数据。
- 退出先停止录制并落盘，再停止后台线程；不能强杀录屏线程。
- 用户取消旧 ACE 兼容方案，改写原生 C++ 模块；不暂停、终止、注入或修改反作弊组件，不自动强制清空工作集。

## Tasks

1. 添加 PowerShell 集成测试，断言 EXE 启动、六页导航、模块窗口归属、单实例以及有界退出。先验证发行 EXE 不存在时失败。
2. 建立 src/modules 源码副本、CMake、独立资源 ID；运行保活和攻速已有测试。
3. 添加 gateway 消息循环与托盘通知代理，模块适配器负责启动、命令、状态和停止。嵌入的录屏与倒计时禁止创建额外托盘图标。
4. 添加六页、统一启动/关闭设置、后台状态、新图标及原生 ACE 优化。错误用明确消息和日志呈现。
5. 编译并运行集成验证：页切换、截图选区取消、倒计时完成、录屏生成 MP4、后台模块停止、单实例和退出。
6. 写 README 与验证记录，将单文件 EXE 输出到 dist。
