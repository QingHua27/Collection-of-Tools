# 植物水彩界面

六个工具页共用原生 Win32 主题层 `src/theme.cpp`。录屏页按参考图的侧栏、标题、双栏卡片、表单和文件行布局重排，其余页面使用相同导航、纸张背景、卡片和按钮。

最终美术：`assets/botanical-paper-reference.png`。通过内置 imagegen 工具生成，以用户提供的界面图为视觉参考；作为 RCDATA 404 内嵌，运行无需外置图片。

生成提示：从参考图移除全部文字、图标、按钮、窗口边框与表格，只保留浅米白纸纹、鼠尾草绿植物、少量赭黄花朵及底部浅山景；保持原图低对比度、稀疏构图与植物水彩画法，中心留白，4:3 横向背景。

Lua 原始内容内嵌为 RCDATA 403，LOL 助手的“复制 Lua”按钮读取 UTF-8 资源，转换为 Unicode 后写入剪贴板；无需外置 Lua 文件。
